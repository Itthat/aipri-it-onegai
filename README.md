# aipri-it-onegai

아이프리 대행 신청 사이트의 기본 틀입니다.

## 파일 구성
- `index.html`: 메인 페이지
- `aipri.html`: 아이프리(세로 기기/버스)
- `onegai.html`: 오네(가로 기기)
- `friendcard.html`: 프카(프렌드카드)
- `style.css`: 공통 디자인
- `or-photos.js`: 아이프리 페이지의 OR 사진 저장 기능

## OR 사진 저장 안내
OR 사진은 브라우저의 IndexedDB에 저장되어 새로고침 후에도 유지됩니다. 이 저장은 현재 브라우저와 기기에만 적용됩니다. 브라우저 사이트 데이터 삭제, 시크릿 모드 종료, 다른 기기 사용 시 사진이 사라지거나 보이지 않을 수 있으니 중요한 사진은 다운로드해 별도 백업해 주세요. `전체 지우기`는 저장된 OR 사진을 모두 삭제하며 확인 창이 표시됩니다.

## GitHub Pages 공개 방법
1. 저장소에 이 폴더 안의 파일을 업로드합니다. 폴더 자체를 한 겹 더 올리지 말고, `index.html`, `style.css` 등이 저장소 최상위에 보이게 올려 주세요.
2. 저장소에서 **Settings → Pages**로 이동합니다.
3. **Build and deployment**에서 Source를 `Deploy from a branch`로 선택합니다.
4. Branch를 `main`, 폴더를 `/(root)`로 선택하고 **Save**를 누릅니다.
5. 잠시 기다리면 Pages 화면에 사이트 주소가 표시됩니다.

현재는 기본 틀입니다. 기존 스프레드시트의 세부 항목과 사진 자료를 확인한 뒤 실제 항목을 채워 넣을 수 있습니다.
